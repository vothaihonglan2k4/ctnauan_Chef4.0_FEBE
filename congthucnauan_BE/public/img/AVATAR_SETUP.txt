========================================
  HƯỚNG DẪN TẠO AVATAR MẶC ĐỊNH
========================================

File default-avatar.svg đã được tạo sẵn.

Tuy nhiên, để tương thích tốt hơn, bạn nên có file PNG:

CÁCH 1: Tải ảnh avatar mặc định từ internet
--------------------------------------------
1. Truy cập: https://ui-avatars.com/api/?name=User&size=200&background=6c757d&color=fff
2. Click chuột phải → Save Image As
3. Lưu với tên: default-avatar.png
4. Copy vào thư mục này (public/img/)

CÁCH 2: Sử dụng Gravatar
-------------------------
1. Truy cập: https://www.gravatar.com/avatar/00000000000000000000000000000000?d=mp&s=200
2. Click chuột phải → Save Image As
3. Lưu với tên: default-avatar.png
4. Copy vào thư mục này (public/img/)

CÁCH 3: Convert SVG sang PNG
-----------------------------
1. Truy cập: https://cloudconvert.com/svg-to-png
2. Upload file default-avatar.svg
3. Convert và download
4. Đổi tên thành: default-avatar.png

HOẶC sử dụng file SVG có sẵn (khuyên dùng nếu hỗ trợ)
------------------------------------------------------
File default-avatar.svg đã hoạt động tốt với hầu hết trình duyệt hiện đại.

Nếu gặp vấn đề, hãy tạo file PNG theo hướng dẫn trên.
